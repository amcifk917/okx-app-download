### 掛單和吃單有什麼差別？

簡單說：

- **吃單**：立即與訂單簿中已有委託成交。
- **掛單**：委託先放進訂單簿，等待其他人撮合。

市價單通常會立即成交，因此較常被視為吃單；限價單則可能是掛單，也可能因為立即成交而成為吃單。最終費率取決於實際成交方式，而不只是你選了市價單或限價單。
